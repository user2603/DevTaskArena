# Task Acceptance Policy (ARCHIVED)

- **Version:** 2.0
- **Status:** SUPERSEDED by version 3.2 on 2026-11-01.
- **Warning:** this copy is kept for historical reference only. Do **not**
  use it to grade any round on or after 2026-11-01.

## 1. Scope

Same as v1: every task folder under `tasks/<developer>/` (never
`tasks/examples/`).

## 2. Core artifact checklist

Count how many of the following four artifacts exist:

| # | Artifact (relative to the task folder) |
|---|----------------------------------------|
| A | `docs/task.md` |
| B | `evaluation/main.py` |
| C | `solution/main.py` |
| D | `preprocess/main.py` |

## 3. Status tiers

- artifact count **>= 3** -> status `certified`
- artifact count **<= 2** -> status `scaffold`

(There are only two tiers under v2.0.)

## 4. Notes

- Only the existence of the artifacts matters.
- `docs/user_system_prompt.md` is not part of the v2.0 checklist.
