# DevTaskArena

Shared collection of small internal tool tasks, one folder per task under
`tasks/<developer>/`.

Layout:

- `docs/task_acceptance_policy_v3.2.md` - the current acceptance policy
- `docs/policy_archive/` - retired policy versions (reference only)
- `tasks/examples/` - one fully worked-out example task (reference only)
- `tasks/<developer>/` - that developer's task folders

Acceptance for a new round is decided **only** by the current policy
document; archived policy versions and historical board rows are not a
rule source.
